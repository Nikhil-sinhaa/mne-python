Fix bug where :func:`mne.io.read_raw_ctf` ignored the pre-trigger baseline of recordings that start before (or after) the sync trigger. :term:`first_samp` is now ``-pre_trig_pts``, so ``raw.first_time`` is negative for a recording that starts before the trigger, and the bad-segment and marker annotations are expressed relative to the trigger (i.e., relative to ``meas_date``), by `Nikhil Sinha`_.
